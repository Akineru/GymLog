# 背阔肌候选遮罩 iteration_03

只生成候选，没有改正式 PNG、`muscle_manifest.json`、其他肌群或应用源码。

底图是 `muscle_back_base.png`，1024×1536。候选遮罩用同一坐标系栅格化，没有裁切或拉伸底图，也没有把遮罩裁到人体不透明区。

## 和正式遮罩、上一版实验的差别

| | 正式遮罩 | 实验 v2 | 本候选 |
|---|---|---|---|
| 不透明像素 | 36911 | 31396 | 26580 |
| 左 / 右 | 18457 / 18454 | 15741 / 15655 | 13288 / 13292 |

邻近正式遮罩里，被本候选盖住的比例：

- 下斜方肌：正式 12.9%，候选 2.9%
- 竖脊肌：正式 10.4%，候选 6.7%
- 臀中肌：正式 13.1%，候选 0%
- 中斜方肌：正式 0%，候选 1.1%
- 上斜方肌：0%
- 大圆肌：正式 38.8%，候选 46.3%

大圆肌比例没有下降。现有大圆肌遮罩本身向下伸进背阔肌上缘一带，所以这个百分比不能单独证明候选盖住了插画里的大圆肌。

## 改了什么

上缘沿肩胛下方可见的浅色分界，没有做成水平截断。内缘留在竖脊肌外侧浅沟的外侧，比 v2 更靠外，竖脊肌重叠从 v2 的 46.4% 降到 6.7%。下缘停在髂嵴白带上方，不再沿白带收成第一版那种圆角，也没有下到臀中肌。外缘比正式遮罩离开透明背景，但仍靠近体侧。

## 没有通过的地方

下端仍然收成尖角。底图在髂嵴上方没有一条可以确认的肌纤维终点，这个尖角是保守收束，不是已确认的轮廓。

上段外缘仍然贴近身体轮廓。这一段插画里肌纤维一直画到体侧，看不到另一条肌界，所以没有把它画成确定的肌缘。

上缘可能略低于肩胛下那条白线，上缘外侧是否切进大圆肌，不能从现有大圆肌遮罩的重叠数字判定。

右侧下外缘有约 55 个像素落在透明背景上（0.2%）。没有为了消掉这 55 个像素去沿剪影裁切。

## 结论

尺寸和透明通道符合：1024×1536，背景透明，肌肉区域为白色。视觉上比正式遮罩少了大块越界，也少了盖住下斜方肌、竖脊肌和臀中肌的面积。下端尖角、上段外缘和上缘与大圆肌的分界仍不确定。不能算修正完成。
