# 练有所迹 1.4 更新公告

**发布日期：2026 年 10 月 18 日**

## 动作库全面升级

- 动作库切换为 **1,324 个数据集动作**。
- 按 **10 种身体部位**和 **28 种器械分类**浏览、搜索和筛选。
- 每个数据集动作都有缩略图，动作详情可以播放动作演示 GIF。
- 动作详情新增三个选项：
  - **动作演示**
  - **正面**
  - **反面**
- 动作演示只在当前页面播放，切换或关闭后停止。

## 训练记录更好读

- 训练记录改为三栏：
  - 左侧：训练部位、动作名称、容量
  - 中间：动作缩略图
  - 右侧：每组的重量 × 次数
- 右侧按 2 列 × 3 行显示。
- 第 6 组显示真实数据；超过 6 组才在第 6 格显示省略号。
- 数据库中的全部组仍保留，详情和编辑页可继续查看。

## 兼容与保护

- 用户自定义动作保留原 ID、名称、PR、归档和肌群关联。
- 旧训练记录、PR、趋势、旧会话编辑和旧备份仍可正常解析旧动作。
- 旧预置动作不再出现在活动动作库，也不会被自动补种。

## 安装说明

Debug APK 可直接安装：

`app/build/outputs/apk/debug/app-debug.apk`

Release APK 已生成但未签名：

`app/build/outputs/apk/release/app-release-unsigned.apk`

项目当前没有配置正式 release keystore，因此 unsigned release 不能直接安装。正式分发前需要使用项目自己的 release key 签名；不要把 debug key 当作正式发布 key。
