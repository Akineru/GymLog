# 练有所迹 1.5 更新公告

**发布日期：2026 年 10 月 21 日**

## 训练记录

- 开始训练后自动开始总计时，顶部显示训练时长。
- 点击训练时长可用滚轮修改时、分、秒，小时上限为 23。
- 训练页新增独立计时器和秒表：
  - 定时器默认 2 分钟，支持 ±30 秒。
  - 点击时间可用分、秒滚轮修改，上限 59:59。
- 点击「完成动作」会记录该动作从加入训练到结束的用时，并收起动作卡片。
  - 动作再次完成会覆盖为新的结束时间。
  - 多个动作的用时可以重叠。
  - 动作用时不重复计入当天总时长。
- 组编辑改为横向布局：组号、负重模式下拉、重量、次数、完成勾选。
  - 完成后整行变绿，长按完成勾可删除组。
  - 新增组继承上一组重量和次数，但不继承完成状态。
- 选择自重组时自动带出身体记录中的体重；没有记录时会提示设置体重。

## 日历与时间

- 删除日历页的训练计时器入口。
- 已经保存的计时记录不会被删除，仍可在设置 → 数据 → 历史记录 → 计时记录中查看。
- 训练总时长会写入日历对应日期的计时记录。
- 日历和首页的当天训练时间以这些计时记录为准。
- 旧的手动计时记录继续保留并计入当天时间。

## 保存训练

- 保存页显示时长、总容量、组数、部位。
- 支持添加照片、填写备注、修改训练日期。
- 保存失败会保留当前页面。
- 新建训练可以舍弃，已有训练可以删除，都需要确认。

## 数据与兼容

- Room 升级到 19，新增动作用时表。
- 训练时长继续写入原有计时记录，不重复计算。
- 旧训练、PR、趋势、动作库、身体记录和旧备份继续兼容。
- 动作用时作为可选备份字段，旧备份缺省为空。

## 安装说明

Debug APK 可直接安装：

`GymLog-1.5.apk`

Release APK 已生成但未配置正式 release keystore：

`app/build/outputs/apk/release/app-release-unsigned.apk`

正式分发前需要使用项目自己的 release key 签名。
